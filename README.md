# Wealth_Operations_Simulator

WEALTH OPERATIONS PRACTICE LAB
=============================================

START HERE
1. Open wealth_operations_simulator.html in Chrome, Edge, Safari or Firefox.
2. Begin with the 'Assignment & Grading' tab.
3. Practice using the Practifi CRM and Tamarac Reporting tabs.
4. Return to Assignment, check your score, and optionally reveal the answer.
